9 个开源项目 · 全部 MIT 许可 · 纯静态部署，无外部 CDN 依赖
Elemental Serenity
★ 画面最好 · 四季 + 昼夜
自然微缩景观：四季切换（春 / 秋 / 冬 / 雨）与实时昼夜，篝火、帐篷、拱桥、池塘。Managers 架构（SeasonManager 808 行 / GrassManager 577 行）。
入口是 splash 页，点 “Explore in Silence” 才进场景。
small-world
12 个生物群系
程序化漂浮岛生态箱：地形、植物、生物、鸟、天气、昼夜全程序化，16 位种子生成，可换群系。
首次会弹帮助面板，按 Esc 关掉（否则挡住整个场景）。
WaterThreeJS
最适合移植
Gerstner 海面 + SSR 反射 + 浪沫 + 体积云 + 水下效果，2869 行。体量最小、无 GLSL3。
右上 GUI 面板可调浪高 / 泡沫 / 云量，可潜到水下。
OceanThreejs
FFT 物理海
基于 FFT 物理模拟的写实海洋：JONSWAP 谱、级联 FFT + 6 路 Gerstner，风速 / 浪高 / 泡沫全可调。
GLSL3 + HalfFloat RT，移植到 three r147 需要改写。
GrassSystemThreeJS
土壤 + 苔藓 + 草
实时程序化土壤沙盒：拖拽雕刻地面、真实土壤、Worley 干裂、苔藓覆盖、GPU instanced 随风草叶。
草和苔藓默认关着 —— 右上 GUI 展开 Grass / Moss Cover 打开。
SnowSystemThreeJS
雪 + 堆积
飘雪 + 积雪着色器：world-space FBM mask 决定堆积位置，抬升 albedo、粗糙度变哑光、冰晶闪烁。
右上 GUI 有 Snow on Ground / Snowfall / Wind 可调。
RainSystemThreeJS
雨 + 涟漪 + 闪电
雨丝、地面涟漪、水洼、闪电，氛围感很强。
面板里 Strike Now 可立刻触发一次闪电。
VegetationGeneratorThreeJS
表面生成藤蔓
在任意模型表面绘制并生成生长的藤蔓与花，BVH surface painter，可载入自己的 glb。
默认是球体预设 —— 在模型上按住拖拽才会画出藤蔓。
jungle-trail
零外部素材
第一人称丛林小径，地形 / 植被 / 水 / 雾全程序化，零外部美术资源，含环境音与步态。
CPU raymarch 体积雾，软渲染设备上会全黑 —— 需要真机 WebGL。
全部项目来自 GitHub 开源仓库，MIT 许可，各项目目录内保留原始 LICENSE。
源码在各场景的 source/ 目录，重新构建：cd scenes/nature && node build-nature.mjs
给 ourworld 的提示：vendor 只有 three r147/r168，r147 无 outputColorSpace、 输出编码 chunk 名是 encodings_fragment（r185 是 colorspace_fragment）—— 直接抄 r185 的 shader 会挂。建议抄 shader 和算法，不换贴图（ourworld 是手绘低多边形风）。
